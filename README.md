# AOB9 — 어센틱 오션브랜치 9팀 고객관리 (구 AFG OC9) (병력고지·보장분석·미청구·상담기록)

심평원·공단 진료자료로 보험 고지 판정표, 진료이력, 미청구 보험금, 건강 분석을 만드는 프로그램입니다.
고객 자료는 실행한 기기 안에만 암호화되어 저장되며, 어디로도 전송되지 않습니다. 이 저장소에는 고객 자료가 없습니다.

- `web/` : PC 프로그램(Tauri) 화면
- `src-tauri/` : 윈도우 exe 포장
- `pwa/` : 휴대폰 설치용 앱 (GitHub Pages로 배포)
- `.github/workflows/` : 저장소에 올리면 exe와 휴대폰 앱을 자동으로 만듭니다
