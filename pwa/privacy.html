병력고지 분석기 개인정보처리방침

시행일: 2026년 10월 24일 · 운영자: 강남혁 (sicrics27@gmail.com)

1. 처리하는 정보

  • 사용자가 직접 입력하거나 첨부한 고객 이름·성별·생년월일·휴대폰 번호·메모·상담 기록, 진료·보장 자료는 사용자 기기 안에만 저장되며, 사용자가 정한 잠금 비밀번호로 암호화됩니다. 운영자 서버로 전송되지 않습니다.
  • 구글 계정 연결 시: 사용 권한 확인을 위해 구글 계정 이메일 주소를 확인하며, 이메일은 저장하지 않고 알아볼 수 없게 변환한 값만 비교에 사용합니다.

2. 구글 드라이브 사용

  • 동기화를 켠 경우, 암호화된 자료를 사용자 본인 구글 드라이브의 앱 전용 숨김 폴더(appDataFolder)에만 저장합니다. 사용자의 다른 드라이브 파일은 읽거나 수정하지 않습니다.
  • 구글 API로 받은 정보는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수하여 동기화 기능에만 사용하며, 제3자에게 제공하거나 광고에 사용하지 않습니다.

3. 보관 및 삭제

  • 기기 안의 자료는 앱에서 고객을 삭제하거나 저장 자료를 초기화하면 지워집니다.
  • 구글 드라이브의 동기화 자료는 구글 계정 설정의 '서드 파티 앱 및 서비스'에서 연결을 해제하고 앱 데이터를 삭제할 수 있습니다.
