"OC9로 복사" 버튼 만들기

AFG OC9 · 회사 DB 고객 가져오기용 (한 번만 하면 됩니다)

PC 크롬 (가장 쉬움)

  1. 키보드 Ctrl + Shift + B를 눌러 주소창 아래에 북마크바가 보이게 합니다.
  2. 아래 파란 버튼을 마우스로 꾹 눌러 잡은 채 북마크바 위로 끌어다 놓습니다. (클릭하지 말고 끌기)

OC9로 복사

  1. DB 사이트(link.afg.kr)에서 고객 상세 화면을 엽니다. 번호가 가려져 있으면 번호 보기를 먼저 눌러 둡니다.
  2. 북마크바의 OC9로 복사를 누릅니다. 여러 명이면 고객 화면마다 차례로 누르세요. 누를 때마다 계속 모이고, 지금까지 모은 사람 전부가 복사됩니다.
  3. OC9 → 도구 · 백업 · 사용자 관리 → 회사 DB 고객 가져오기 → 붙여넣기 → 가져오기.

휴대폰 (크롬 앱)

  1. 아래 코드 복사를 누릅니다.
  2. 크롬에서 이 페이지를 별표(☆)로 북마크 → 바로 뜨는 수정을 누릅니다.
  3. 이름을 OC9로 복사로, URL을 지우고 복사한 코드를 붙여 넣어 저장합니다.
  4. DB 고객 상세 화면에서 주소창에 OC9로 복사라고 입력 → 아래 목록의 별표(★) 북마크를 누릅니다.

삼성 인터넷에서는 안 될 수 있어요. 휴대폰은 크롬으로 해 주세요. 이 버튼은 지금 보고 있는 화면 글만 복사하고, 어디로도 보내지 않습니다.
